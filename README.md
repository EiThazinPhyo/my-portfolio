Personal Portfolio Website

This is a personal developer portfolio website designed to showcase web development projects, skills, and contact information.

1.Live Demo
You can check out the live website here: 
[https://eithazinphyo.github.io/my-portfolio/](https://eithazinphyo.github.io/my-portfolio/)

2.Technologies & Libraries Used
- **HTML5:** Semantic markup structure
- **CSS3:** Custom styling and layout design
- **JavaScript (ES6):** Interactive elements and dynamic features
- **Bootstrap 5:** Responsive design, grid system, and pre-styled components

3.How to Run the Project
1. Clone or download this repository.
2. Open the project folder.
3. Double-click or open the `index.html` file in any web browser (Chrome, Firefox, Edge, etc.).

4.Features & Implementation
- Fully responsive layout for all device screens (Mobile, Tablet, Desktop).
- Showcases skills in WordPress, PHP, Python, and modern web development.
- Highlights community events, workshops, and project portfolios.
- Clean code structure with modular folders for CSS, JS, and Images.
